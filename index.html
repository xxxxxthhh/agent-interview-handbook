Agent Design Interview Handbook

Agent 设计面试手册先交卷，再揭晓，再接追问

这不是又一本讲 ReAct 的书。每个单元是一道没见过的 Agent 设计题：限时交一版方案，对照参考交卷和评分表，用两分钟英文讲出来，再一层一层接面试官的追问。原理部分回链到本系列的 AI 系统工程手册和两本 Claude 认证手册，这里不重讲。

30 Minutes 考前半小时

挑一道端到端题，配两张深挖卡

  1. 按场景选 1 个 Part A 题：看任务类型、错误代价、动作是否可逆。
  2. 从它的追问里挑 2 张 Part B 卡，看一句话框架和取舍表（约 15 分钟）。
  3. 打开计时器口述一遍（约 5 分钟）。
  4. 最后 10 分钟只做一件事：接一条没见过的反例追问，或者写一版交卷提纲。
岗位类型建议组合（示例）
垂直 Agent 研发A06 长任务 + B06 评估 + B03 上下文
Forward Deployed / 交付工程A04 或 A03 + B07 放行点 + B01 编排光谱
Solutions / 售前架构A02 或 A04 + B01 编排光谱 + B09 成本

组合是准备建议，不是任何公司的出题规律。收到面试邀请后按实际轮次调整。

Part A

端到端交卷

6 题 · 每题 20–30 分钟
  • A01改代码的 Agent模糊需求 → 可验证条款 → 受限修改 → 独立放行
  • A02深度研究 / 搜索 Agent P0跨来源取证、引用可核查、来源矛盾怎么办
  • A03客服 Agent（含语音变体） P0政策步骤交给代码，风险动作先确认，语音链路有超时和转人工
  • A04受监管文档审查 Agent P0固定工作流 + 逐字引用 + 权限跟人走 + 签字人放行
  • A05浏览器 / computer-use Agent观察与动作分离，不可逆动作前停下
  • A06长任务 goal Agent目标与验收在会话外，检查器判完成，预算与升级终止循环
Part B

横切深挖

10 张 · 被追问时翻
  • B01编排光谱 P0步骤能否预定、有无外部反馈、能否独立并行
  • B02Tool / MCP 接口设计模型只提议，执行器验证参数、权限与副作用
  • B03上下文工程与缓存任务真值、可重取观察、稳定前缀分层
  • B04Memory 设计只记有来源、有权限、有生命周期的事实
  • B05为什么不 multi-agent独立可合并才试，和等预算单 Agent 公平对照
  • B06Agent 评估 P0可重置任务集，分开量结果、规则、轨迹、一致性
  • B07注入、权限与人工放行点 P0不可信内容与授权决策隔开，按动作风险定放行
  • B08错误恢复与幂等错误先分类，写入要幂等键、对账、补偿
  • B09延迟与成本拆关键路径和单位成本，守住质量门槛
  • B10上线后的质量回溯从用户结果倒查检索、模型、工具、权限、人工节点

题目均为自拟训练题，场景与数字为虚构练习设定，不代表任何公司的真实面试题或真实系统。
